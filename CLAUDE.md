# BOM Reader — Claude Code Instructions

**Work here. Do not hand off.** The gates live where the corpus lives: the
pre-commit validators, the parity checks, `quality_meter`, and the baseline
comparison all run in this repo. A session operating on BoFM from elsewhere has
no gate coverage — on 2026-08-06 exactly that produced 103 dangling canon
citations, caught only when this repo's pre-commit hook ran.

## What this is

A colometric reading edition of the Book of Mormon at **bomreader.com**, for ESL
readers, children, and newcomers. Each line renders one **atomic thought unit**
(ATU). Reference implementation for the `readers-*` siblings.

Pipeline: `v0` source → Stanza parse → `v1` clause atoms → `v1.5` binding rules →
`v2` deployed (`data/text-files/v2/`, generated by `scripts/bofm_generate.py`) →
`build_book.py` → `books/*.html` → the site. Bump `sw.js` after source changes.

## What is true today (2026-08-07)

- **The deployed edition is systematically coarse.** Against Skousen's
  sense-lines: 16,481 lines to his 28,828 over 6,593 word-identical verses —
  **1.75×** — and we break fewer times in **81%** of verses. Cross-corpus: 16.2
  words/line against 7–9 for every gold-substrate sibling. See
  [`2-evidence/`](2-evidence/).
- **Measured quality is F1 ≈ 0.67** against a 33-verse stratified gold yardstick
  (2026-05-28, never re-run) — divergence in both directions, over-split in
  sermon/Isaiah, over-merge in doctrinal/narrative. Do not repeat the older
  "mostly correct" framing without that qualifier.
- **The mechanical binding layer is at its ceiling.** Remaining defects need
  token-in-context judgment. Three levers, in order of preference: binding rules
  in `bofm_v1_fabric.py`; UD corrections to `v0-cache-conllu`;
  `data/text-files/v2-adjudicated/overrides.json`.
- **The EModE parser-training route is CLOSED** — a PCEEC-trained parser lost a
  blind two-adjudicator gate to off-the-shelf Stanza 21–6. Do not reopen without
  real in-register gold. (LLM post-editing of Stanza output is a *different*
  mechanism and is not closed.)
- **Live parse is `data/parses/v0-cache-conllu/`**, never
  `data/parses/ensemble/stanza/` (superseded reference only).
- `scripts/bofm_generate.py --stage v1` renders the bare clause layer to
  `data/text-files/v1-clause/` as a parallel view. Default stays `v2`.

## Two gates that will bite you

- **No validator detects over-merge.** It is Stan's red line and the automated
  layer is blind to it. Only adversarial audit and `quality_meter` see it.
  Validator-clean is never evidence that a merge is safe.
- **The baseline stopped working as a control on 2026-05-29.** Four validators
  sit above it from accumulated intentional change, and `--baseline-check` is
  counts-only, so a fix and a new break cancel out. **Never `--update-baseline`.**
  Do not `--no-verify` without Stan saying so. Tracked in `Pending-Decisions.md`.

## Third-party material

The Book of Mormon text is public domain; other editors' *arrangements* are not.
Parry's parallelism overlay was removed from the build and the live pages on
2026-08-07. Skousen's and Parry's line data stay gitignored and local. Measured
results (counts, rates) may be committed; **a list of their break positions may
not** — with the public text that losslessly reconstructs the arrangement.
