## What this project is (for collaborators / forks)

A web-based colometric reading edition of the Book of Mormon at **bomreader.com**, for ESL readers, children, and newcomers. Each line on the page is an atomic thought unit (ATU); modern-mode pill toggles archaic→modern in place; audio narration per chapter for some books. Reference implementation for gnt-reader / tanakh-reader siblings.

- **Source files**: `data/text-files/v2/` (one ATU per line) — the **deployed mechanical-first / pure-method edition**, generated by `scripts/bofm_generate.py`. It **REPLACED the old hand-edited v2-mine as source of truth on 2026-05-22** (commit `1a980bf`), the same process Tanakh + GNT shipped on; the live edition is method-output, NOT a protected hand-edit layer (old hand-edits recoverable via git). Do not treat it as a hand-edit oracle — measure method-vs-anything on the bidirectional test; the deploy bar is "new AND superior by the method's own yardstick."
- **Build**: regenerate the corpus via `scripts/bofm_generate.py`, then `python build_book.py --all` → `books/*.html`; bump `sw.js` cache version after source changes
- **Live deploy**: bomreader.com (GitHub Pages, auto-deploys from main)
- **Audio narration**: pipeline at `colab/samuel_pipeline.ipynb` (1 Nephi complete; 2 Nephi 1-5; Enos complete)
- **PWA features** (annotations.js, firestore.rules, manifest.json, sw.js, narration.js): partial-exploration state; subject to separate clean-up assessment (Stan flagged Firestore-PWA as dead-code experiment, 2026-05-19)
- **Validators**: `validators/run_all.py --baseline-check` blocks regressions; wired as `.git/hooks/pre-commit`
