# Archived Scripts

This directory holds scripts that are no longer in active use but are preserved for provenance.

## Conventions

- A script is moved here when its output is now produced by another path (e.g., a tier collapsed, an index format changed, a feature was retired)
- One-line entry per archived script in the Archived list below, with the date moved + reason
- Active vs. vestigial boundary stays visible — future sessions don't waste cycles asking "is this still used?"
